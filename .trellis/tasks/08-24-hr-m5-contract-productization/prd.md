# HR M5 玉舟劳动合同产品化

## Goal

把已通过 T2 迁移进入 `hr_contract/hr_contract_change/hr_contract_type` 的玉舟劳动合同历史转为可日常使用的业务功能：HR 可按员工、状态和到期窗口管理合同，负责人只能在获准数据范围内查看必要状态，员工只能查看自己的合同摘要；历史源信息、工资字段和内部审计字段不得泄露。

## Requirements

1. HR 合同是人力资源模块内的员工生命周期子域，不复用招商租赁合同权限。
2. 权限至少拆分页面、园区读取、团队读取、本人读取和管理动作；管理权限不得自动授予部门负责人或员工。
3. 所有查询由服务端解析 `park/managed_org_tree/self/none` 数据范围，客户端条件只能缩小范围。
4. 列表支持员工姓名/工号、合同状态、到期日期窗口和分页；所有历史记录可继续加载。
5. 详情显示主合同与有序续签/变更链；普通投影不得返回 `sourceSnapshot`、租户园区、创建修改人、软删除、版本、旧文件路径或工资金额。
6. 员工本人只能看到合同编号、类型、起止日期、状态和变更摘要；负责人不得看到薪资字段和旧合同正文存在性。
7. HR 可创建新合同和续签/变更草稿，但不得编辑已迁移历史快照；写入需幂等、事务、锁、状态校验和无正文审计。
8. 前端为列表优先工作台，新增/续签表单显式展开；桌面和手机采用共享设计系统。
9. 保持 T2 的 802/357 总账、映射、回滚和不可变历史语义，不修改已执行的 `000238`。

## Acceptance Criteria

- [ ] 原子权限、生产 seed、页面路由和菜单授权闭环。
- [ ] API 列表、详情、本人、团队和管理动作具有精确数据范围与显式投影。
- [ ] 历史合同和变更不可修改；在线合同状态机和并发写入可验证。
- [ ] Web 列表、筛选、到期提醒、详情和显式办理区可用且移动端无横向溢出。
- [ ] 单元、契约、真实 PostgreSQL、lint/typecheck/build、浏览器、三端一致和生产发布门禁通过。

## Non-goals

- 本切片不迁移合同正文或附件二进制；这些进入受保护文件迁移阶段。
- 不把劳动合同与招商租赁合同模型或权限混用。
- 不实现电子签章、外部劳动备案或自动续签。
