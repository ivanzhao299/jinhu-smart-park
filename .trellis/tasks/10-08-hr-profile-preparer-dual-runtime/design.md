# 实现设计

expectedRuntimeCommit 继续绑定部署来源及 .release.json，新增可选 expectedApiCommit/expectedWebCommit，缺省为来源版本。主机传输把 API 版本放入原采集器配置，并注入已有 observe 回调，回调调用封存的实际镜像观察器且分别传组件版本、记录来源版本。采集器的前后身份比较、只读快照、来源认证、文件输出及代码摘要完全不变。

保留严格请求键集和40位小写SHA；空工作流可选输入只在环境入口解释为未指定，结构化请求的非法值拒绝。真实观察器测试覆盖混合版本、任一版本不符、前后身份变动及旧同版默认。描述文件从真实导出同步。
