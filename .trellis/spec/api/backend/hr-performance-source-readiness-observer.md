## 2. Signatures
scripts/diagnose-hr-performance-source-readiness.mjs exports diagnosePerformanceSourceReadiness(deployPath,run?), performanceSourceReadinessSql, parsePerformanceSourceReadiness(raw), validPerformanceSourceReadiness(value). Built-ins only; exact module runs via SSH stdin.

## 3. Contracts
Fixed tenant10000001/park20000001, one REPEATABLE READ READ ONLY snapshot,5s statement/2s lock timeout. No builder/math/verifier/capability/locking helper calls. Inline only succeeded-operation T0 candidates with exact row uniqueness/hash/verified owner/live scoped employee. Subject counters represent this conservative intersection, not all resolved records; zero does not establish unavailable source. Six raw/visible/exact-map/gap families, separate308/310/309 ledger counts, raw-master resolution/status/link counts, five-channel presence. EXISTS/aggregates prevent fanout. Exact keys, denominators and inequalities are in task research/output-contract.md.

Digest hashes sorted scoped raw(kind,id,batch,map,identity,rowHash) tuples only, PostgreSQL JSON text/C ordering; empty SHA256([]) is deterministic. Fixed formalContinuationReadiness=UNVERIFIED and productionBusinessWrites=0. No personal/financial rows or values returned.

## 4. Validation & Error Matrix
Missing/extra/duplicate keys (including escaped equivalents), negative/non-safe/non-integer count, invalid lowercase64hex hash or contradictory subset/partition fails HR_PERFORMANCE_SOURCE_READINESS_RESULT_INVALID. Query/startup failure: HR_PERFORMANCE_SOURCE_READINESS_PROBE_FAILED; bad path: HR_PERFORMANCE_SOURCE_READINESS_PATH_INVALID. Unknown remote error: HR_PERFORMANCE_SOURCE_READINESS_REMOTE_FAILED. No raw errors or zero fallback.

## 5. Good / Base / Bad Cases
Good: visible fact with wrong source-row hash has an exact-map gap. Base: empty scope gives zero counts, exact empty digest and UNVERIFIED. Bad: duplicate joins inflate counts, conservative subject intersection zero is labelled zero stored resolutions, or308 relationship receipt is treated as full310 fact qualification.
