# Contract operation continuity

The six contract write adapters accept an optional caller key, preserving existing fallback compatibility. The page retains one bounded current operation attempt bound to authenticated context, operation route and normalized body. Unchanged unknown-result retry reuses its key/body. Any form input, form/record/context/action change or confirmed success releases the attempt; an infinite body-key cache is incorrect because reopening a completed operation would reuse stale replay.

Freeze all relevant controls while the ledger synchronous write mutex is active. Existing ledger generations suppress old-context, navigation and unmount callbacks. Before releasing an attempt, require a nonempty response id and exact contract id for edit/review/contract action or change id for change action; mismatches remain unknown and retryable with original key, with no success receipt. Create results use their returned generated id.

Persist the real server result and a minimal business receipt label before refreshing list/detail. Show contract number, business status or change sequence, never request keys/technical UUIDs or salary fields. Refresh failure cannot turn a known successful write into a write failure. Retain receipt across read failure/retry; existing refresh controls issue reads only, clear recovered refresh warnings, and new identity/record selection clears unrelated receipts. Missing business display fields are unavailable, not invented.

Preserve existing employee selection, all contract/agreement/calendar fields, salary/file permissions, version/state rules, reminders and full scoped export. No schema, backend business-rule or signature action changes. Use DS surfaces, readable spacing and390px/desktop component verification. Verify lost-response unchanged retry, edited/restored inputs, known-success reopening, action/record isolation, malformed receipt, saved-write list/detail failure, read-only recovery and late callbacks; synthetic tests do not replace actual role business acceptance.
