# Technical Design

## 数据流

生产安全种子 → 校验固定租户/园区及唯一账号 → 创建或恢复专属角色 → 以显式权限白名单替换该角色权限 → 恢复专属用户角色绑定 → 软删除两个指定旧绑定 → 校验最终精确集合。

`/users/me` 继续按现有授权链路聚合角色权限，前端菜单无需增加账号特判。

## 安全边界

- 角色目标由固定角色代码确定，不从用户名推导。
- 用户迁移是经过审阅的固定账号映射，只作用于固定租户/园区。
- 全新环境尚未创建业务账号时只建立角色基线并跳过账号绑定；账号重复或现有绑定异常仍失败关闭。
- 角色权限采用精确集合收敛；缺失权限代码会导致事务失败。
- 只撤销 `PROPERTY_STAFF`、`MAINTENANCE_ENGINEER` 两个已确认旧绑定，不影响其他账号。
- SQL 在单事务中执行并在结尾断言最终状态。

## 发布与回滚

- 通过新增生产安全种子执行，不修改历史迁移；全新环境和存量环境均可收敛。
- 代码回滚不反向恢复越权角色。业务如需回退，应由管理员显式重新授权并保留审计。
