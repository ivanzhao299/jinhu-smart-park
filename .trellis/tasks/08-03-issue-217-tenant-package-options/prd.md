# 修复租户套餐选项为空

## Goal

让租户开通流程列出后端实际允许解析和绑定的有效套餐目录。

## Requirements

- 套餐候选接口必须与 `TenantsService.resolvePlan` 的“当前作用域优先、默认平台套餐目录兜底”语义一致。
- 不改变套餐管理页的当前作用域编辑边界，不把其他作用域套餐暴露为可编辑记录。
- 候选仅包含启用、未删除的套餐，并按套餐编码去重且保持稳定排序。
- 开通租户页面必须处理加载、空目录和失败状态，不能提交不存在的套餐编码。

## Acceptance Criteria

- [ ] 当前园区无 `sys_plan` 时仍能列出默认平台目录的有效套餐。
- [ ] 当前园区与默认目录同编码时优先当前园区版本且只展示一次。
- [ ] 页面选择的每个套餐编码均可由租户创建服务解析。
- [ ] API/Web 回归测试及相关质量检查通过。
