# 考勤运营员工选择

考勤管理中的当日排班、人工打卡和日考勤重算共用一个明确选择的员工。进入页面后先按姓名或员工编号搜索，或用“员工上一页／下一页”浏览全部在职人员，再选择员工。候选每页20人，不再受前100人限制。筛选或翻页保留已选员工，页面显示“当前操作员工”，不会自动换成第一人。

选择员工和业务日期后，可指定班次保存当日排班；人工打卡还需事件唯一键、打卡时间及类型；日重算采用页面显示的员工、日期和规则版本。未选择员工时，这三项按钮不可提交。默认业务日期和月份按上海时区计算。

候选接口为 `GET /hr/attendance/employee-options?page=1&page_size=20&keyword=...`，沿用考勤运营权限，只返回当前租户园区内在职员工的ID、编号、姓名。它不依赖员工档案读取权限，也不返回联系方式、工资或个人档案。原操作接口的权限、幂等和业务验证保持有效。

本改动补齐现代页面的选人能力，不表示原玉舟全部考勤规则已经等价。历史月历模板仍属于来源记录，不作为员工实际出勤；真实月结、工资输入和岗位验收须另行核对。
