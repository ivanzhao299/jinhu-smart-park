# Design
Dedicated list-query DTO extends existing policy query paging/keyword but applies only to owned-period list; employee options retain current DTO. Parameterized filter predicates share exact definitions with projected closed/current. No user interpolation; later revision probe must ignore status filters. Append optional filters/page-size to hrApi without breaking existing calls. Reuse ScopedLedgerExport, existing CSV escaping and layout tokens; local CSS only layout. Decode exact six bases/four totals using existing source structure and reusable correction-input where valid, with strict failure for incomplete amounts. Read scopes and field projections unchanged.
