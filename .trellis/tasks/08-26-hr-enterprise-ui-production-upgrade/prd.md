# HR 企业级前端生产化

## Goal

收敛 HR 工作台信息层级，统一核心页面视觉与 390px 移动端生产体验

## Requirements

- 不改变 HR 权限、API、数据范围与业务状态机。
- 工作台优先呈现真实待办，库存总数不得伪装成待办。
- 所有已授权入口仍可从工作台和左侧菜单到达。
- 统一 HR 页面标题、KPI、表单、空态和操作区层级。
- 桌面端提高信息密度，390px 端保持触控友好且无横向溢出。

## Acceptance Criteria

- [x] 工作台仅展示非零业务待办或服务失败提醒。
- [x] 快捷入口按人员运营、组织效能、薪酬保障分组。
- [x] 公共 HR 样式覆盖工作台、审批及复用该样式的核心页面。
- [x] HR 契约、Lint、TypeScript、CSS 架构与 production build 通过。
- [ ] 生产桌面与 390px 浏览器验收通过。
- [ ] 三端一致后完成合并、部署与健康检查。

## Notes

- 生产基线审计确认原工作台十余指标等权铺满、审批 KPI 排版拥挤，390px 存在低效双列大卡片和可视溢出。
