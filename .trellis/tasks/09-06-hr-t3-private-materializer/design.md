# Design

CLI materialize-production-t3-decision-candidates.mjs --config <private path>. Export materializeProductionT3DecisionCandidates(configPath,{currentHead,maximumReadBytes}?) with test-only function options matching existing T2 pattern; CLI exposes no override. Config exact {formatVersion:1,triple,stagingDir,artifacts:{sourceManifest,targetInventory,t0Candidates},outputDir}. Descriptors exact absolute canonical path/SHA. Source manifest verifier returns canonical manifest SHA bound by target inventory; source S/M must match triple. Current clean HEAD must equal triple C. Reuse pure assembler's full sixteen-table inventory and T0 validation; never replace stale source/target hashes.

Input config<=1MiB, metadata/T0/inventory<=32MiB each; each fixed T3 JSONL source<=64MiB and aggregate input<=128MiB. Test budget can lower, never raise. Read64KiB chunks with fatal UTF-8 decoding and <=1MiB JSONL lines, preserve every nonempty row, authenticate inode/dev/size/times/mode/ownership/single-link/no-follow before and after reading; compare source file hashes and row counts to BOTH stage and source manifests. Fixed domains attendance/policies/insurance and fixed matching files/tables. Optional manifest identity fields must match source receipt references. Recognized structural drift fails before output. No data values in errors.

OutputDir must be canonical owned0700 and empty, distinct from stagingDir; output fixed files t3-phase.json, t3-candidates.json, t3-policy-lineage.json. Each0600 exclusive/no-follow, fsync, stream read-back hash and size. Per artifact<=384MiB, aggregate output including receipt<=1GiB, preflight sizes/hashes before creating outputs. Reserve output descriptors exclusively to avoid concurrent reuse. A failure preserves partial data files; rerun requires a different empty output directory. Final t3-materialization-receipt.json created last exclusively after successful readbacks, containing hashes/bytes/counts/source-manifest references/triple/status/HOLD and no source values or private paths. Sole rollback exception approved by the coordinating owner: on a caught late failure remove only this invocation's newly created completion-receipt inode after verifying dev/ino still match; never delete an existing/replaced receipt, any data artifact or source file. Failed receipt cleanup reports a distinct stable error, never success. Receipt presence alone is insufficient after abrupt interruption: downstream acceptance must validate every hash plus successful command outcome. Return only safe summary counts/reasons/hashes.

Root provides shared pure helper production-t3-artifact-json.mjs: productionT3ArtifactJsonChunks(artifact) yields exact canonical JSON plus newline in per-record chunks for plain top-level artifacts with records arrays, and hashProductionT3ArtifactJson(artifact) computes those bytes. Lineage file envelope uses records:policyRecoveries. Root changes assembler phase hashing to the same helper while preserving canonical parity. Implementer consumes helper for size/hash preflight and buffered64KiB output rather than full stringify; final safe receipt is small. No circular imports. Do not edit legacy phase producer or target model, change activation, or claim approved decisions.
