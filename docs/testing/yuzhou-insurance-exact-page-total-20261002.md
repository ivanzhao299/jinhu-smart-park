# 社保页面精确汇总与手机金额显示

原页面以 `Number` 对已加载记录的个人缴费求和，再 `toFixed(2)`，可能丢分。现在直接把API十进制字符串转换为整数分后相加，再输出两位小数字符串。大金额 `90071992547409.91 + 19.99` 显示 `90071992547429.90`；30条数据库金额上限的合成记录汇总为 `299999999999999999.70`。负数和跨零抵消准确，负零归一。任何缺失、NULL、异常格式或非分精度输入均显示 `—`，不当作零；空页仍显示 `0.00`。

仍为“本页个人缴费”，不扩大为整个筛选结果汇总，不改变金额权限。实际页面交互测试覆盖精确值与无金额权限时隐藏；合成授权不能证明生产岗位已验收。手机三列概览原先把长金额拆行，现仅社保页面在720px以下采用两列，金额卡片单独占满一行；复用共享Design表面，不改变颜色、边框或其他HR页面。
