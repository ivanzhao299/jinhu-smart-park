# 修复用户默认园区选项为空

## Goal

保证用户新增和编辑抽屉在目标租户园区候选可用后再允许选择与保存默认园区。

## Requirements

- 打开新增/编辑抽屉和切换租户时，明确区分“正在加载”“加载失败”“无园区”和“候选已就绪”。
- 必填默认园区不得以无选项的空选择器呈现为可提交状态。
- 编辑时保留用户当前默认园区和可访问园区；候选切换后清理不属于目标租户的旧值。
- 不扩大普通用户的跨租户读取权限，继续遵守现有超级管理员边界。

## Acceptance Criteria

- [ ] 新增用户时默认园区候选来自当前选中租户。
- [ ] 编辑用户时异步响应到达后默认园区正确选中且可访问园区正确勾选。
- [ ] 切换租户期间禁止使用旧租户候选提交。
- [ ] 加载失败或园区为空时显示明确提示并禁用保存。
