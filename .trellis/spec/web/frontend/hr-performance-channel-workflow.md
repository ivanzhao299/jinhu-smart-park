## Lifetime and evidence
The full keyed auth identity owns projections, drafts, attempts and requests. Abort/generation guards suppress late reads and old identity completions. Modern workbench, templates and policy saves share one synchronous writer lock. An uncertain attempt retains all payload data; a definite400/401/403/404/422 or ordinary409 releases it while preserving editable drafts. Record matched success before refresh; if input refresh fails, remove the old actionable projection and offer read recovery, never the old write again.

CSV keeps legacy dimension-only columns unchanged. A result set containing channel records adds explicit mode/input revision/full candidate evidence columns, subject to the same self-result visibility policy. No salary is serialized.
