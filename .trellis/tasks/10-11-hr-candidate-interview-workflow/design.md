# Design

## Contracts
Add a focused HrCandidateInterviewService (registered in existing HrModule) and DTO file, with routes in existing HrRecruitmentController, typed Web transport and CandidateInterviews component. Reuse existing recruitment permissions/audit/idempotency patterns, avoiding a broader refactor.
Routes: GET candidates/:id/interviews/:interviewId (exact scoped record for conflict comparison), GET candidates/:id/interviews (page/page_size), POST candidates/:id/interviews, PUT candidates/:id/interviews/:interviewId, GET candidates/:id/interviews/:interviewId/history (page/page_size). All paths parse UUIDs. POST only scheduled and expectedVersion=0; PUT requires integer expectedVersion>=1. Full request snapshot fields roundLabel(1..120), startsAt/endsAt(strict valid ISO seconds with explicit Z/offset; end>start), location(1..240), interviewerName(1..100), status scheduled/completed/cancelled, outcome pending/pass/fail/hold, resultNotes nullable<=2000, cancellationReason nullable<=1000. Strings trimmed, required values must be genuinely nonblank. Scheduled requires outcome=pending and null result/cancel fields; completed requires nonpending outcome and nonblank resultNotes, cancellationReason=null; cancelled requires pending outcome, nonblank cancellationReason, resultNotes=null. Do not silently drop incompatible supplied fields. No guessed duration ceiling, no min-now, no overlap/auto-promotion rules. Interviewer is an explicit business name supporting internal/external people without unauthorized staff/user reads.

## Persistence
New unique migration000358 after verifying no collision: hr_candidate_interview current rows + hr_candidate_interview_history append-only full immutable snapshots. Composite scoped candidate, interview and actor FKs; unique (tenant,park,id,version) history; useful candidate/time indexes. State/check constraints mirror DTO invariants. Histories may use explicit typed fields or a whitelist complete JSON snapshot; transport must expose exact full business snapshot + stable history ID/time/scoped actor display name. No raw actor ID or contact fields. No backfill/seed. Protect history UPDATE/DELETE with trigger. Candidate lock first for writes, scoped interview lock/CAS second. Current write/history/required audit one actual DataSource transaction. Normalize TypeORM INSERT/UPDATE RETURNING actual driver shapes, as proven in PR950. Reads repeatable consistent count/page with required read audit and candidate scope existence; no need write locks for read.

## Web
Key component by selected candidate. Own independent cancellable/generation-guarded list, detail/history reads. Use strict payload checks and explicit loaded state. Form draft + frozen intent(key/body/baseVersion) separate from reread server snapshot. A failed receipt retries exactly; editing creates new intent; conflict requires visible server vs draft comparison and explicit acknowledgement before rebasing/key change. Require matched saved ID/candidate/version before clearing intent, preserve draft on invalid/missing receipts. Synchronous savingRef and existing parent busy gate prevent duplicate calls and candidate switching/parent actions during writes. History loads independently, explicitly return page1 after save; stale response cannot apply to a different selected interview. Multiple rows displayed as DS cards, desktop/phone. datetime-local seconds step1 uses explicit Asia/Shanghai conversion; label 北京时间, send +08:00, do not accidentally use device timezone. API accepts second-precision timestamps only so editor round trips without truncating fractions. No browser native alert/confirm as workflow.

## Release
Root owns the sole local PG process, browser and production release. Implementer writes runnable isolated PG test but does not create/drop DB, open browser, commit, push, merge, deploy or spawn agents. Root prepares DB/migrations and runs test, freezes code and follows existing reviewed release chain. Tests/synthetic screenshots are not actual role UAT or GroupWeb parity. Technical rollback reverts app while additive tables remain; applied migration not edited.
