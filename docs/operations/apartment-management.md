# 园区公寓管理操作指南

## 适用范围与角色

本流程适用于园区人才公寓、员工宿舍和高管宿舍的房源、入住、在住与退房管理。

- 公寓管理员：维护房源床位、核对申请、分配床位、办理入住/退房交接、管理文书。
- 公寓审批人：审查住宿必要性、期限、费用承担、安全要求和分配建议。
- 公寓审计员：只读查看申请、审批、在住、交接和文书记录。

## 标准业务流程

1. 房源建档：从园区资产房号选择未占用单元，设置公寓类型、性别策略、床位数和设施。系统同步建立占用投影，避免与租赁等业务重复占用。
2. 入住申请：填写申请人、所属组织、紧急联系人、实际入住人数、随住人、车辆、计划期限、特殊需求和申请理由，确认安全承诺后提交。
3. 审批：审批人核对申请资料后选择批准或驳回。批准必须填写批准起日、费用承担和安全要求；押金、月度费用、批准止日和分配建议按实际填写。驳回必须记录可执行的理由。
4. 床位分配：批准后按批准期限加载可用床位，经办人核对房型、性别策略和审批建议后显式选择。保存时系统会再次校验床位冲突。
5. 入住交接：现场核对房间、家具家电、卫生、钥匙和门禁卡，登记水电表读数与异常，上传至少一张现场照片后确认入住。
6. 在住管理：在住期间的维修申报使用现有住房维修/工单流程。现阶段应在工单描述中记录公寓入住编号，不得在公寓审批页直接操作财务收款。
7. 退房验收：先从在住记录发起退房，再按与入住相同的清单核验设施、钥匙、卫生、表读数和照片。存在损坏或缺失时必须填写异常说明，并线下发起相应工单/费用核定。
8. 文书归档：使用已发布模板生成申请表、审批表、安全承诺书、入住交接单或退房验收单，通过线上签署或纸签扫描件归档。

## 交接与能源表计

- 交接面板按入住记录对应的统一房号加载能源模块已启用的水表、电表；现场人员逐表核对编码、当前值和单位后录入。
- 房号已有水电表时必须完整登记全部表计，系统在同一事务生成已确认能源读数、更新表计当前值并推进入住或退房状态。
- 读数低于表计当前值会整体拒绝，交接状态不会提前变化。应先复核抄表照片、表计是否更换或能源档案是否有误，再由能源管理员处理。
- 房号尚未接入水电表时仍可完成交接档案，但不会虚构能源读数；后续应由能源管理模块补齐实体表计。

## 状态与操作限制

| 状态 | 允许的主要操作 |
| --- | --- |
| `draft` | 提交、取消 |
| `submitted` | 审批、取消 |
| `approved` | 选择床位分配、取消 |
| `rejected` / `cancelled` | 终止，保留历史审计 |
| `allocated` / 入住 `reserved` | 办理入住交接 |
| `checked_in` / 入住 `active` | 在住管理、发起退房 |
| `checkout_pending` | 完成退房验收 |
| `completed` | 只读查看与档案审计 |

## 上线与人工确认

- 发布前依次执行数据库备份、`pnpm db:migrate`、API/Web 发布和健康检查。
- 业务负责人需确认本园区的押金、月度费用、减免和费用共担规则；系统当前只记录审批条件，不自动生成收款。
- 需在真实桌面端和 390px 手机视口验收长表单、床位选择、照片上传和交接操作。
