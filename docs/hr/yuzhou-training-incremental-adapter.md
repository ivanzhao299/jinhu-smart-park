## 同一固定入口

已审定dbo.trainhis规则复用统一构包程序的可选`trainingRecords`，或受控staging配置的`trainingManifest`。后者指向既有trainhis.jsonl及摘要绑定manifest，自动检查行数、原行摘要与明确旧传输编码。接口描述`docs/hr/yuzhou-import-interface.v1.json`由实际配方自动导出；同格式新批次不重做全量历史分析、切片和A/B。

- 来源id为SQL Server int，身份为SHA256(`dbo.trainhis` + NUL + 原id)，不按课程名或批次生成。
- 员工依赖准确dbo.person来源身份；同包先处理员工后处理培训，不按姓名关联。预览允许同包待创建员工；提交必须解析已建立正式员工，不能使用预览占位关系。
- 课程名最多160字符；起止日期取原无时区ISO时间的本地日期，校验日历、时间和顺序；学时1至999999整数。异常不默认当前日期或一学时。
- organ、attainment、test、trainmoney保留原资料和逐字段待接入说明，不猜提供方、成绩、结果、币种或评语。未知非空新列明确失败，只验证变化部分。
- 事实摘要不含提取日期或未投射字段；原行摘要仍绑定全部来源。未投射字段变化不冒充现代业务更新。

预览和提交要求课程管理、计划管理、进度管理三项权限全部具备；查询要求全培训读取或上述完整管理权限。合同/员工管理权限不能代替培训权限，团队/本人读取不能查询整批导入。Web同步检查完整管理集合，服务端重新验证，原始数据包不进入审计正文。
