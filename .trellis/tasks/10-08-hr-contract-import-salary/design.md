# Design

Reuse normalizeHrMoney for canonical fixed-two-decimal admission, null allowed. Keep salary column mapping separate from public action snapshot terms. Add fields to shared whitelist, builder, original full-T2 witness, actual importer read/write. Require compensation management on manage requests containing salary fields; status remains metadata only. Web detects salary field labels without retaining values. Recipe byte changes are admitted by exact third fingerprint while retaining original and seven-term fingerprints; profile collector/adapter unchanged.
