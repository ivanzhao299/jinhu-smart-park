Freeze candidate, 2026-10-17, source HEAD `ef715dc497e6cbae10d0c149021ef5b3b32eeea7`. All names marked NEW below are deliberate additions, not claims that tables/routes already exist. This contract resolves the former inventory's open baseline/cohort questions. No production data was queried.

## 1. Unit, provenance, and modes

The unit of review activation is one scoped `hr_performance_source_draft(kind=review)` stable master identity. One activation creates one template version, one cycle, one selected employee, one review. Never group masters merely by person/session/item. Template activation is one scoped template draft and creates an ordinary draft version. Source families outside the selected rubric remain in the immutable373 manifest; they are not silently inserted as unrelated formal items.

Two explicit review modes: `qualified_source` and `manual_current`. The former requires every qualification gate below and produces rev2 from original manifest; the latter requires actual manager authorization, explicit current employee/date/org/businessPeriodRef/reason, stores source reference only, and stops at empty rev1. Both use normal lifecycle thereafter. An unresolved historical person may be manually assigned to a current employee ONLY in manual_current; this never changes309/310/sourceQualified. A qualified-source employee must exactly equal the resolved historical employee. Template-only activation may use an unqualified source as a reference draft, visibly `historicalQualification=unqualified`; it cannot create a qualified review by itself.

Activation never supplies submission, approval, score/result status, acknowledgement, calibration membership, original actor or original timestamp. Original source authors/time/grades/aggregate outputs remain provenance only. Manual current mode cannot use source numeric/text values as initial input, even when a manager asserts that they are correct. Ordinary stage editing remains available.
