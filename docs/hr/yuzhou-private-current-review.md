# 当前隔离核对定位的私有只读导出

本诊断分支不合并业务应用，不部署服务。复用原T5来源/回执绑定与所有者、唯一有效映射、合同账号及财务影响分类，只提取当前身份歧义、家庭、证照候选的员工UUID、来源/行/回执摘要及四类财务关联布尔标记。没有姓名、证件、工资值或来源解密。

SQL采用REPEATABLE READ READ ONLY、30s语句/2s锁超时、ROLLBACK。严格验证原集合认证、有限字段、UUID/摘要、原因、重复与最多500项；不是截断查询。候选总数需与本次聚合分类一致，变化则停止取证。此名单只是当前核对定位，尚未证明人工核对完成或所有隔离无影响。

公开仓库不得保留明文定位。生产端随机AES256GCM加密，RSA-OAEP-SHA256包裹密钥；脚本仅含本轮公钥，私钥保留本机0600。Actions只有加密包和聚合元数据。下载后在私有0700目录解密、验证，再交由已有权限的HR按需核对。公钥不授予生产访问、业务权限或解密权限。私钥不可进入Git、日志或附件；失去私钥须重新生成新接收公钥并重新只读观察。

本轮测试：原运行/影响契约41项、新查询/结构/密文篡改契约3项、真实PostgreSQL68检查和零临时库残留。只读事务阻止写入，历史/未知/失效映射不输出；原集合漂移拒绝。完整迁移、业务写入或真实HR角色验收不由这些测试替代。
