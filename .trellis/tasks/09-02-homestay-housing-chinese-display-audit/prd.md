# 民宿与长租中文名称显示专项核查

## Goal

全面核查 Web 端民宿（homestay）与长租经营（housing，含改名后入口）所有用户可见页面中，本应展示中文名称却直接展示英文枚举、状态码、ID、UUID 或数字代码的问题，产出可复核的问题矩阵和统一修复方案，供后续另行批准实施。

## Confirmed Scope

- 枚举 `apps/web/app` 下 homestay/housing 相关的全部路由、页面组件与入口别名。
- 覆盖列表表格、详情字段、表单只读态、看板/统计卡片、picker/选择器回显、空态和错误信息。
- 检查状态/枚举字段及单元、租客 Party、园区、楼栋、经办人等关联实体字段。
- 对照 Web 渲染源、共享/前端既有 label map、API DTO/实体/服务查询与实际返回投影。
- 每处缺陷按 A（前端缺映射）、B（后端缺名称字段）、C（已有映射但漏用）、D（值无中文产品定义）分类。

## Deliverables

- `docs/reviews/homestay-housing-chinese-display-audit-2026-09-02.md`：逐页问题矩阵（HCD-001…）、分类统计、证据、统一修复方案、后端补字段清单、D 类定名清单、改动面和验证方案。
- 本 Trellis investigation 任务及其调查记录。
- 仅包含调查文档的报告 PR，经一轮 review、CI、合并，并确认 main 双绿。
- 终报包含问题统计、根因分布、修复方案摘要、需用户定名清单和改动面预估。

## Constraints

- 本轮零产品代码改动；只允许调查任务材料和核查报告变更。
- 不开修复实施 Issue；复核批准后另开修复队列。
- 不直接操作生产环境，不触碰他人容器、主 Chrome 或 HR 系列代码/材料。
- 不记录真实业务数据、敏感信息或未经验证的证据。
- 仅推送报告分支；main 只通过 GitHub PR merge 更新；禁止 force push。
- 等待 review、CI 或 merge gate 时持续等待，不提前结束回合。

## Acceptance Criteria

- [ ] 两模块全部相关路由/页面组件有可复核的枚举清单，含改名/兼容入口。
- [ ] 所有目标展示面逐字段检查原始值直出、已有 label 映射和关联名称回显。
- [ ] 每个问题具有路由、字段、描述性当前样例、证据位置、根因分类和建议修法。
- [ ] API 契约核对能区分前端漏映射与后端缺字段，结论引用 `file:line` 或符号。
- [ ] 报告列出可复用映射资产、建议归属层、后端补字段、D 类定名项、改动面与含 390px 的验证方式。
- [ ] 根因分类统计与问题矩阵逐项一致。
- [ ] Git diff 证明没有产品代码改动。
- [ ] 报告 PR 完成一轮 review、CI、merge，并确认 main 双绿。

## Out of Scope

- 实施任何 label map、API 名称字段、页面渲染或测试代码修复。
- 创建修复 Issue、部署、生产验证或真实数据抽样。
- HR 系列及 homestay/housing 之外模块的横向整改。

## Open Questions

- 无阻塞问题；D 类值若存在，仅在报告中列出并等待产品复核定名。
