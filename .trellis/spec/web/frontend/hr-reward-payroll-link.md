# 奖惩工资输入关联

## 入口
仅已批准详情且具 HR_REWARD_READ 与 HR_REWARD_LINK_PAYROLL 展示；使用现有共享写锁，办理中禁切换详情、列表页。

## 选择
每页20完整分页，以月份/月结补正批次/版本为标签；选中完整对象跨页保留，提交精确 id+version，不手填内部编号。

## 响应
校验 case/status/page/page_size/总数/精确页长、唯一ID、正整数版本与批次、月份和枚举；异常响应关闭写入，允许重新读取。

## 重试
未知写入结果保留请求体与幂等键，禁止换目标重放；已确认400/403/404/422拒绝才允许新请求键；同步重复提交只产生一个调用。

## 已提交
确认 linked 后显示成功并隐藏表单；刷新失败仍显示已保存，重试只读取。已有引用包括失效或不可读取目标均禁止覆盖。

## 生命周期与样式
按认证上下文及事项重建组件，卸载后忽略迟到写入；共享 DS、表单和移动卡片，390px无横向溢出且按钮至少44px。

## 验证
实际组件6场景、适配器和父页精确权限测试，桌面/390px合成接口检查；真实角色和工资金额验收独立进行。
