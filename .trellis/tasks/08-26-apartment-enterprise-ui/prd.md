# 公寓管理全页面企业级样式统一

## Goal

审计并统一公寓管理全部功能页面，复用 HR 模块设计系统，覆盖桌面与390px移动端。

## Requirements

- 覆盖 `/apartments`、房源、申请、在住、退房和文书六个生产页面，不遗漏共用办理面板。
- 复用 HR 已采用的全局 `ds-page`、`ds-hero`、`ds-panel`、`ds-kpi-*`、`ds-command-*` 和 `ds-mobile-record`，局部 CSS 只保留公寓业务布局。
- 统一 Hero、栏目导航、指标卡、表单面板、记录卡、按钮、空态、错误态的层级、框线和留白。
- 指标信息先于长办理表单出现；页面操作顺序符合“概览 → 当前栏目 → 办理 → 记录”。
- 390px 下不得出现页面级横向滚动；栏目导航和表单改为可触控的单/双列布局，按钮保持可操作尺寸。
- 不改变 API、权限、幂等、业务状态机和数据投影。

## Acceptance Criteria

- [ ] 六个页面使用同一个企业级栏目导航组件，活动栏目、标题和说明一致。
- [ ] 总览及业务页的 Hero、指标、面板、表单、记录卡间距与 HR 设计系统一致。
- [ ] 入住申请页指标位于长表单之前；勾选承诺不再呈现为细长输入框。
- [ ] desktop 与 390px 均无 document 横向溢出，移动端导航、表单、记录卡可完整操作。
- [ ] Web lint、typecheck、production build、CSS check、路由合同和浏览器验收通过。

## Notes

- 这是样式与信息层级改造，不扩展公寓业务范围，也不修改生产数据。
