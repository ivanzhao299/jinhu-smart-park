# 单线实施计划

1. 读取规范与确切现有接口，复用直接/间接依赖、模块AST和仅结构快照。收敛范围端口、企业模型、schema/升级及配置，在research记录决定；不重复旧源分析或同一结构盘点。
2. 实现部署模式配置、真实企业/成员及双模式范围解析。集成规则兼容；独立模式无需园区/资产表；拒绝模式混用、跨范围和撤权。
3. 实现同内核独立入口、独立初始化和文件边界。实际空独立库启动，根据明确失败补足必要依赖，不用全园区库替代。
4. 接通实际前端登录、企业范围、导航、组织/员工和关键HR操作；DS、真实API、保存回读、失败续办及桌面/390px。
5. 批量执行Shared build、API/Web affected lint/typecheck/build、双模式PG/HTTP及集成auth/scope/idempotency/HR必要回归。命令和原始日志入私有manifest，相关输入未变的通过项不重复。
6. 串行独立全范围审查，修复并锁定source/hash、资源和清理。新鲜fetch后核对基线/重叠/冲突，再PR、CI、合并及默认集成部署；不自动公开独立实例或复制生产。
7. 按实际证据记录child状态，父目标仍保留真实岗位、全量工资、旧端等价、整体迁出恢复及独立M0-M5/P0-P4。

## 成本与检查

COST_GUARD：不创建新代理；复用一名已释放实施者作为唯一代码写者，root维护需求和外层checkpoint。实施者不得再派子代理。最多两次同因自动修复，再做一次定向根因分析。不重复初始化已保存结构；新模式实际验收所需专属资源除外。等待仅确定性句柄，不启动模型轮询。

检查包含：实际双模式PG/HTTP、集成身份/范围/上下文/幂等与被影响HR、独立进程/health/版本/停止回执、上传与角色负例、Web真实桌面390px、正式CI release-smoke。配置解析或静态清单不替代业务运行。

结束记录变更文件、确切命令/结果/跳过理由、重试、源码hash、当前句柄、缺口与下一步；token/费用未暴露则记不可用。
