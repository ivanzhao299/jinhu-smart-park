# S4 未发布工资历史的精确期间冻结

基线：主干 `1c055c92`；候选 `codex/yuzhou-unpublished-reconciliation-source-20261002`。

本轮交付数据库冻结原语、复核权限 API 与显式冻结来源的模拟读取。000319/000320 为新增前向迁移，不修改成功历史迁移。已发布批次的现有模拟路径保留；暂存批次仍必须提供同范围、同月份的冻结来源，不退回实时历史表。

冻结严格指定租户、园区、暂存批次、账套、月份、成功 T4 回执 binding、预期记录数及内容 hash。只复制选定账套和月份的已映射快照与项目，以 JSONB 保留源字段、类型、null 标记和 numeric 精度；不复制全部工资历史。上限 5000 快照、200000 项目，聚合前核对实际数量。

锁住快照、项目、期间和来源映射的短事务禁止并发追加与回退 DDL；批次、回执和控制批次行锁阻止回退状态改变。使用 READ COMMITTED，等待锁后读取已提交事实；错误隔离级别拒绝。来源必须由成功、当前数据库的 T4 控制批次唯一持有，跨园区、来源漂移、回执回退、错误数量/hash 均拒绝，不生成半份证据。

冻结结果 append-only，同一来源 hash 重试复用同一 UUID；不改变原批次发布状态、不创建工资条、不触发发薪。数据库函数 SECURITY INVOKER，表与函数 PUBLIC 权限撤销。POST /hr/payroll/reconciliation-sources 仅 review 权限可创建，保存核对原因并同事务写入无金额、无明细的元数据审计；审计失败则创建失败。接口有幂等拦截和 body-free 审计，不增加部门经理或员工访问权。

simulate DTO 可选 reconciliationSourceId；来源必须匹配租户、园区、原批次与关账月份，成功回执和控制批次再次受行锁核验。只读取副本中的快照与项目，JSONB 在 SQL 内转 text 后再用 numeric(20,4) 投影，不经过 JavaScript 数值解析。记录 source UUID/hash 到不可变 run 证据与输入 hash，000320 的复合 FK 防止跨批次绑定。公式仍需批准，净额映射、考勤、薪酬和社保缺件继续拒绝；不自动填零。

隔离最小结构 PostgreSQL 测试：14 项正反例通过，另验证追加、回执回退、回退 DDL 三类并发被阻断及输入不变。每次临时库实际删除并查询零残留。该测试不替代完整迁移、API 角色或真实金额验收。

完整迁移：使用独立 `postgres:16-alpine` tmpfs 容器与项目原始 `scripts/db-migrate.sh`，运行句柄和结果存于私有断点。没有复用生产凭据、没有宿主端口、没有真实数据。调用 API 时必须在调用函数前单独设置 statement_timeout；函数内设置不能替代外层语句的超时起点。

完整迁移 000319 在空库通过且记录 checksum 匹配；000320 在同一完整结构升级通过。切片升级仅提供 000320 的目录并显式关闭该测试目录不存在的历史 alias 清单；不是全库新版本 Release Smoke。上线前仍需孤立 CI 对最终两份迁移跑完整路径。
