# 修复巡检点位楼栋楼层房源级联

## Goal

让巡检点位的楼栋、楼层、房源选择遵循真实资产层级，避免保存互相矛盾的关联。

## Requirements

- 新增、编辑表单中，楼层仅显示所选楼栋的楼层，房源仅显示所选楼层的房源。
- 清空或修改楼栋时清理不合法楼层与房源；清空或修改楼层时清理不合法房源。
- 编辑已有点位时保留合法现值；历史不一致值不得被静默继续提交。
- 列表筛选区使用相同级联规则，避免查询参数组合互相矛盾。

## Acceptance Criteria

- [ ] 选择楼栋后楼层候选全部属于该楼栋。
- [ ] 选择楼层后房源候选全部属于该楼层。
- [ ] 父级变化会原子清理失效下游值。
- [ ] 纯逻辑回归测试覆盖新增、编辑、清空与切换父级。
