# S2 回聘现代页面接入与验证

完整长目标保持：历史数据延续、关键 HR 业务闭环、旧功能复现、分模块生产与独立产品验收。

## 实施

在员工生命周期接入正式回聘申请、修改、提交、退回、独立复核、取消及确认；离职员工档案提供携带精确员工 ID 的入口。列表和分页保持当前员工筛选；招聘页面明确只取初次入职申请，避免将回聘草稿送入错误的编辑表单。使用同一正式档案，不按旧/新来源拆分人员。

新增受已有权限保护的回聘参考选项接口，按当前园区分页搜索离职员工或上级候选，仅返回业务所需字段。当前部门和岗位只含可用引用；部门变化清空旧岗位。创建发送所选员工当时的版本，翻页不换绑版本。退回编辑时重新读取当前员工事实后保存；失败不清空填写内容。制单人不显示自审按钮，生效日期未到不允许确认。

复用全局 DS 面板、按钮及卡片，只增加回聘领域布局。完整业务卡片在桌面仍显示，避免 icon-leading grid 把文字压成竖排。手机搜索翻页控件整块换行且保持44px触控高度。
