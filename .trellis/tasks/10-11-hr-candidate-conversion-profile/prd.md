# 候选人转预入职衔接正式员工档案

## Goal
未来候选人转预入职时，已录入的个人手机、个人邮箱和证件资料进入正式员工档案，避免再次录入。

## Requirements
- 不重放历史导入、历史录用或回填已有员工；工资月份已确认2026-07，吴恩国负责。
- 沿用转换权限；有资料需要衔接时要求员工档案管理权限，缺失明确提示。自动内部衔接不增加敏感详情读取权限，也不返回资料正文。
- 同事务完成转换、档案补缺、清单、名额、版本及必要审计；失败全部回滚。
- 仅填空字段；已有不同资料、删除档案、重复证件、损坏源资料均明确冲突，不覆盖、不截断、不猜测证件类型。

## Acceptance Criteria
- [x] 新员工资料自动承载，既有一致资料保留，其他字段原样保留。
- [x] 权限、资料长度、损坏密文、冲突和唯一约束具备可验证处理。
- [x] 元数据凭证不含个人正文；定向测试、类型检查和真实隔离数据库验证。
- [ ] 前序PR953发布完成后再集成发布；不得重叠生产写入。
