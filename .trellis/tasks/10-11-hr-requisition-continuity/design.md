# Design

Baseline5df047e744d7563ab0470ac7561af7e01cae9989, authoritative workspace /Users/mac/.codex/worktrees/hr-payroll-modern-run-workflow-20261009. Reuse hr_recruitment_requisition version/status schema, existing HR_REQUISITION_READ/TEAM_READ/MANAGE and candidate conversion locking.

GET /hr/recruitment/requisitions/:id returns full business projection including version, approvalNote, names and hiredCount. Full READ or TEAM_READ scoped predicate for reads; MANAGE plus full READ for editing/options (avoid widening team access). GET :id/history?page&page_size same read scope. GET :id/reference-options?kind=organization|position|owner&keyword&page&page_size requires READ+MANAGE; minimal same-scope enabled choices, paginated (20 default,50max), optional organization filter for position selection. PUT :id requires READ+MANAGE and generic IdempotencyInterceptor (no candidate private fields in payload), expectedVersion, changeReason and optional provided fields including status. Null only allowed for optional positionId/date/approvalNote. Missing fields preserve. Trim strings, strict real YYYY-MM-DD, no-op400. Scoped locked row true version CAS, safe conflict marker/code for Web explicit rebase, scoped unique409. Required same-manager audit records only IDs/versions/state; complete non-sensitive before/after history in new forward-only000360 migration. Immutable history record carries resulting global version, operator/time/reason, before/after names frozen. Project actor name, no raw actor ID necessary in user UI.

State contract: draft->open|cancelled; open->paused|closed|cancelled; paused->open|closed|cancelled; closed->open; cancelled terminal. Cancellation only hiredCount0. Opening/reopening requires headcount>hiredCount. Metadata updates allowed except cancelled; headcount positive >=hiredCount. Organization/position changes prohibited after hiredCount>0; immutable candidates/employee links. Changed org/position/owner validate same scoped enabled rows under SHARE locks; position must belong to chosen org. Unchanged historical/inactive references preserve, do not force blanket rebinding. No generic directory grants. Existing conversion increments requisition version atomically with hired_count; maintains lock ordering candidate thenrequisition to avoid reversal. Maintenance only locks requisition then scoped references, never candidate rows.

Web new route-local RequisitionOperations selected by exact row ID, current/history independently lazy; parent synchronous lock blocks refresh/switch and other actions while saving. Reference pickers independently paged, selected choice persists off-page. Full draft compare to original, partial payload changed fields only; uncertain exactkey/body retry; CAS explicit comparison and confirm preserves dirty fields only. Successful mutation updates parent list row before optional reads; permission context changes clear all. DS panels/cards/form-field/buttons; CSS layout only, no desktop card invisibility or text squeezed vertical. No production test rows.
