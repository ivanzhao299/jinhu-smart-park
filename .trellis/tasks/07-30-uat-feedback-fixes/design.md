# 测试反馈缺陷修复设计

## Isolation

每条反馈从 `696873a` 创建独立分支，并在 `/tmp/jinhu-uat-worktrees/<slug>` 中实现。分支之间不互相合并，避免一个修复隐式依赖另一个修复。

## Boundaries

- 删除提示：后端返回中文业务错误，前端使用可见弹窗呈现删除失败。
- 楼层附件：保持共享上传组件；编辑不强制选择新文件；删除时同步清理楼层平面图引用。
- 文件名：在 API 上传入口统一规范化 multipart 原始文件名，保持 ASCII 名不变。
- 合同：创建草稿后进入房源关联步骤，不放宽提交前必须有关联房源的金融约束。
- 字典：按 `dict_code` 直接加载，避免依赖字典类型前 100 条。
- IoT：修正点位接口的数组契约，不改变 API。
- 能耗：用可读账单项选择器替代 UUID 手输，不改变调整/红冲审批与入账规则。

## Compatibility And Rollback

- 所有变更保持现有 API 路径和数据库结构。
- 每个提交可独立 revert。
- 若某分支验证失败，不影响其他分支继续实施和审查。
