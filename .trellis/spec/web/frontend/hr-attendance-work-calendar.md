# 工作日历维护与排班参考

WorkCalendarPanel在HR考勤页由精确HR_ATTENDANCE_OPERATE门控，操作角色没有考勤读取权限时仍可进入工作日历，不能请求历史员工月历。身份上下文key重挂载，月份读失败不能盲写。日期旁展开编辑；完整版本CAS、原因、稳定重试键、同步提交锁，失败保留草稿。保存回执先更新当前版本，历史刷新独立失败/重试，成功不能被刷新失败覆盖；月份/身份变化清理旧上下文，历史分页完整可达。

日期范围排班显式读取当前范围工作日历，可选择明确working日期；未知/未设置保持未选择，手工全选与手工日期继续可用。读取失败单独提示并禁用按工作日选，不伪装空日历；不会自动改变既有排班或已封账输入。

使用全局DS primary/secondary按钮，44px触达、字段间距，历史使用DS记录但局部布局在桌面/手机均显示，不能依赖默认手机列表的隐藏规则。月份全部日期可达，长名称换行，不竖排挤压。
