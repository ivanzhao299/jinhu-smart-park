# 现代绩效奖惩依据查看

## 入口
现有有权读取的现代绩效卡片显示查看奖惩依据；不清除未提交评价草稿，不新增来源跳转或权限依赖。

## 读取
独立useHrResource加载与取消；page/page_size=20，完整total、有序页和明确空状态。读取失败保留单独重试。

## 约束
校验reviewId、准确页长、页码、总数、唯一行ID、正整数版本和可空业务标签，损坏响应不作为记录展示。

## 生命周期
认证/园区沿用父Workspace key，切换评价使用组件key；分页/过滤/父刷新清除选择。卸载或迟到读取不能显示旧scope记录。

## 语义
展示绩效发布时冻结的业务编号、奖励处分类型、发生日期、版本和保存时间；明确作为评价参考，评分由原流程办理。不把缺失标签猜测为当前来源值。

## 样式
复用DS与performance-template的editor/records/reviewWorkbench；桌面记录容器必须可见，手机不横向溢出，按钮44px。

## 验证
实际组件、适配器及父页草稿延续/身份清除测试，桌面/390px浏览器；合成fixture不能替代生产角色验收。
