## 1. 项目与目标

- **项目**：jinhu-smart-park（金湖智慧园区），多租户 SaaS 管理平台 monorepo。
- **本模块业务目标**：园区餐厅**自建但承包经营**，公司统一经营/收款/结算。
  - 顾客（员工）通过**二维码真实收款**（微信/支付宝）付款，资金进**公司统一收款账户**。
  - 员工享**午餐补贴虚拟钱包**：按月发放、用餐则扣、**月末过期清零**（不累积、不兑现、不找零）。
  - 餐厅管理员负责上架餐品、触摸屏 POS 收款。
  - 承包方**月末凭员工消费净额与公司财务对账结算**（公司就 `company_payable` 划付承包方）。
  - 平台/管理费可配置，**默认不启用**。
- **多端**：触摸屏 POS（横屏 16:9）、员工个人中心、餐厅管理端、财务端、（承包方视图经结算/对账页体现）。
- **技术栈**：
  - pnpm workspaces monorepo；
  - 前端 `apps/web`：Next.js **App Router** + React + TypeScript，自有设计系统（`ds-*` CSS Modules，组件包 `@jinhu/ui`，源码在 `packages/ui`）；
  - 后端 `apps/api`：**NestJS** + TypeORM；
  - 数据库：PostgreSQL（本地以 **Docker** 容器运行）；前向 SQL migration；
  - 共享常量/权限：`packages/shared`。
- 仓库本地根：`/Users/mac/Documents/jinhu-smart-park`（远程为 GitHub，私有库）。
