# Design

One root MJS producer with pure builder and private CLI. Builder consumes validated T2 records plus exact evidence identities and produces the existing yuzhou_hr_t2_change_classification_candidates envelope. Reuse verifyProductionT2StagedRecord and source-manifest verifier; do not change target model or dictionary resolver. Current source manifest and all four T2 file hashes/counts are required at the I/O boundary. Approved evidence constant is the inspected routine SHA; hash integrity is not a human approval. Missing/ambiguous parents and owner mismatch result in needs_review, with only aggregate reason counts in summary. Downstream assembly still rejects missing parents.

Config: formatVersion, triple, stagingDir, sourceManifest:{path,sha256}, routine:{path,sha256}, outputPath. Current HEAD required in CLI. Private data/config inputs owned regular no-follow single-link 0600, dirs0700, bounded32MiB/file128MiB total. Archived SQL code is a separate pinned non-executable evidence class: owned regular no-follow single-link, stable fd metadata, cap256KiB and exact allowlisted actual bytes, without requiring permission changes or copying the existing archive. Its original permissions are allowed because no source data is output/executed and byte identity is fixed. No credentials/config inference. Never relax private staging or output protections.

Pure API agreed with implementer before tests. CLI output only counts/hash/HOLD; artifact contains source hashes, changeType and evidence hash, never raw business fields. Output exclusive and readback verified. Original staged data is only consumed internally.
