# Design

One pure module consumes a staged source record with verified row identity/hash plus explicit resolved dictionary values. It emits model-normalized fields, not a write plan or authorization. Reuse production-import-target-model and production-import-payload-generator normalization; leave the isolated SQL loader unchanged.

Contract start/end/signature dates come from named source fields. Date-derived term and renewal count consume the existing transform's named semantic decisions. Ambiguous compacttime, totalcompacttime and continueyears stay in source_snapshot. First/last signatures and cumulative term stay null until separate history evidence exists. Nullable flags are unresolved, not silently false. Change datetime precision stays in source_snapshot when projected to date columns. Evidence uses the same projection identity formula as the existing T2 phase materializer, with no binary/locator values.

No I/O or credentials. The upstream caller still owns C/S/M, artifact bytes, approved dictionaries, target identity and dependency/collision decisions. Stable errors contain no values. Tests use invented records only.

Candidate graph accepts verified artifact content and explicit per-source resolved decisions, preserving their byte-hash references for the private materializer. It is an in-memory stage between the private reader and existing freeze/payload generator. It must cross-check artifact content bindings itself, but never describe self-reported hashes/resolutions as external source or approval verification. Full inventory validation reuses the existing exported validator, then indexes all tables (its returned Map contains T0 only). Output ordering is by phase/table dependency then source identity, independent of input order. Unresolved rows have no usable target fields/ID; dependent rows cannot become executable candidates. No changes to the production writer or activation contract.

Private entrypoint reuses the existing bounded descriptor reader for nonempty JSON/artifacts; handles only manifest-declared empty stage files with the same no-follow/owned/single-link/0600 checks. Bound all bytes before parsing. Pin source manifest bytes as expected by the inventory. Recompute the existing dictionary canonical newline hashes and T2 source-file evidence rather than generating another dictionary. Optional change decisions bind source identity plus source-row hash to C/S/M; missing items yield unresolved candidates, not guessed classifications. Do not write a new artifact until every input and the complete graph have validated. Stable codes and aggregate output only.
