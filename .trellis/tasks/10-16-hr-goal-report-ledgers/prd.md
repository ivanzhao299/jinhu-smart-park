# 目标与工作汇报完整授权台账导出

## Goal

在现代目标管理和工作汇报页面提供完整、按现有权限与筛选条件导出的正式业务台账，便于HR、部门负责人和员工核对、留存及日常汇总。复用已有目标定义/版本、进度和汇报状态链，属于长任务S5高频报表及当前运营能力，不替代旧端规则等价和真人验收。

## Requirements

- 目标台账包含当前已授权定义、层级/归属、指标、精确权重与数值、状态、版本及期间；进度记录包含授权目标、进度、总结、风险、下一步和记录时间。字段不得超出现有读取投影。
- 工作汇报导出沿用本人/团队范围和既有筛选、草稿/提交/审核可见性，保留完整工作内容及有权读取的审核结果。
- 每次导出必须覆盖所选范围的全部记录，使用一致读取快照。超过明确上限时拒绝并提示缩小筛选，不能默默导出第一页或截断前N条。
- 数值保持十进制精度，CSV沿用既有安全单元格处理和中文业务表头；权限、账号、园区或筛选切换后不能下载旧范围结果。
- 桌面及390px均可操作，使用全局DS。保留现有新增、维护、进度和审核功能，不修改正式数据或扩大访问范围。
- 先核对是否存在可复用导出入口或完整分页工具；若已存在，应接通和修复实际缺口，禁止重复建设。

## Acceptance Criteria

- [ ] 目标、目标进度、本人/团队工作汇报三类台账在现代页面可按授权完整导出，字段、范围和筛选均可核对。
- [ ] 真实独立PG/HTTP验证权限先于探测、跨园区/跨部门/非本人拒绝、单快照完整性、上限和审计失败；业务写入为0。
- [ ] 实际组件及CSV测试覆盖完整范围、数值/特殊文字、失败恢复、身份/筛选切换丢弃旧响应；桌面及390px浏览器验收。
- [ ] API/Web必要lint、typecheck、相关测试和构建通过；独立检查；最新基线集成、合并、部署与运行证据分别记录。
- [ ] 不宣称新报表等于玉舟全部报表/规则等价、真实岗位签署或独立HR产品完成。
