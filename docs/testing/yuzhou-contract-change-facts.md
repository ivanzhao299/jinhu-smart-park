# 现代合同续签及变更的明确期限与签订日期

现代变更草稿接受可选contractTermMonths（明确整数0至1200）及signatureDate（有效YYYY-MM-DD）。拒绝null、字符串数字、非法日期；终止不能登记新期限。UI复用Design System，空输入省略，0明确保留。

事实保存在既有source_snapshot.modernContractFacts的version=1窄对象；API仅投影两个明确字段，不返回原快照。历史变更和本人简化投影省略新增事实，组织范围及敏感读审计不变。旧现代草稿没有新对象时视为未登记；旧signed_at不被解释为真实签订日期。

确认续签后，新期限和签订日期采用本次明确登记值；缺失时不沿用旧合同段，包括无结束日期且本次日期不变的续签。变更/更正改变日期但未提供期限时清除旧段期限；日期不变时保留。变更/更正的签订日期保留在本次记录，不覆盖主合同原签订日期。续签清除无法证明的新累计期限，不猜算原算法；首次/最近签订历史维护仍待独立业务确认。动作快照保留变更前后的期限、累计、续签次数及本次事实，occurred_at记录实际办理时间；新生效变更signed_at保持NULL，不用服务器办理时间假冒法律签订时间。既有已生效或历史行不批量修改。
