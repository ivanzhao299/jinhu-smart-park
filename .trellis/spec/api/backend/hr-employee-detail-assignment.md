# Employee detail assignment labels and source-separated employment dates

`detailEmployeeForActor` verifies principal tenant/park and existing employee park/team/self scope before relationship or date queries. Detail adds `assignmentDetails` name/status allowlists and `employmentDates`. Employee directory and other generic projections keep their existing allowlist. Attendance card remains excluded.

The aggregate `probation_end_date` mixes imported confirmation dates, onboarding plans and modern confirmation actions. Carry it only as `unclassifiedRecordedDate`; missing and malformed values differ. Never infer its meaning from matching dates or expose it as a probation-end fact. `plannedConfirmation` reads pending participants of submitted/approved modern probation applications; `confirmedEmployment` reads effective, nonhistorical confirmation events. Bind each query to tenant, park and employee. Keep repeated same-day facts, validate calendar dates in the supported 1000–9999 domain, and classify invalid sources independently. Existing authorized legacy formaldate rendering remains separate; no raw profile, workflow snapshot or new permission is introduced.

Organization and position queries bind tenant, park, nondeleted and the saved employee relationship. Position must match the primary organization. Disabled rows retain their business name with inactive status; no relationship, unavailable relationship and older API response are distinct. Display never falls back to database IDs.

Manager names use existing employee access checks. A managed-tree actor may show their own linked employment name, already resolved as the scope anchor, when they are the selected employee's manager; this does not permit another employee lookup or sensitive-profile access. Self or managed-tree scope cannot turn a manager UUID into a hidden employee lookup. Missing/hidden references share an unavailable state. Only safe not-found is absorbed; database failures propagate. No sensitive profile lookup, new permission or account assignment is introduced.
