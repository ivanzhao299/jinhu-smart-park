基线：main c282c655。该切片的生产运行验收待发布后另行记录，不改变 PR784 发布范围。

## 已实现

- 差异详情只读取核算运行中冻结的来源 ID、版本、格式和哈希；与该结果的历史/现代来源 FK 对应后返回最小元数据。没有查询当前最新版本，也没有返回全部冻结 JSON 或社保金额输入。
- 缺失、双来源、ID 不一致、非法版本或现代哈希/格式不完整时返回 unavailable；旧核算不从当前事实推测来源。
- 页面显示历史期间或现代确认及冻结版本，不展示内部 ID/哈希。未保留可展示证据时明确说明。原差异卡片使用桌面隐藏的移动列表类，改为 DS scene 卡片并以单列、12px 间隔承载文字。
- 保留原详情权限、租户园区过滤、分页及必需审计。不发布工资、创建工资条或发薪。
