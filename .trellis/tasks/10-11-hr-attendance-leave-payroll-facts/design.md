# 设计

数据流：批准请假及已批准销假 → 已刷新日结果 sourceTrace → 月汇总 approved_leave_minutes → 不可变工资输入 approved_leave_minutes → 明确工资公式依赖 → 页面/导出。

新增列对既有数据允许 NULL，NULL 表示未保留该事实；新生产者拒绝缺失或畸形日数量。累计检查整数边界。不得用 COALESCE 把未知转换为零。沿用当前期间锁、审批事实新鲜度和封账更正规则，不重写已封账输入。

新工资依赖拟用 hr:批准请假分钟。保持既有表达式解析和已批准版本/hash 的兼容性。正式来源选择的覆盖性与实际计算均要对新依赖检查字段可用性；双轨消费者采用相同语义。原批次数量未知时，更正数量差也未知，附可用性说明。

UI 使用全局 Design System，显示实际分钟与未知区别，不让来源内部版本标记成为业务标签。旧输入保持可查看；实际规则决策仍由吴恩国确认。
