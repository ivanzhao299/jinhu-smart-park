## 行为

- 只有成功读到当前员工完整档案，或成功确认档案不存在，才显示编辑表单并允许保存。
- 读取失败、脱敏响应及其他员工响应不允许编辑；其他员工档案不会展示。
- 切换员工、刷新列表和上下文失效清除读取就绪状态，旧响应沿用请求范围保护。
- 保存成功但回读失败或只返回脱敏结果时，准确说明已保存并要求重载，不能误报写入失败或允许空白重写。
- 未改权限、API写入语义、历史记录、账户绑定、日期保护及数据库迁移。
