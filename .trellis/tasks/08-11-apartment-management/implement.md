## Quality gates

- 每个子任务：focused tests → shared build → API/Web typecheck/lint/build → migration fixture（如涉及 DB）→ desktop/mobile browser check。
- 涉及生产部署时必须执行健康检查和 Docker 清理。
- 任一迁移、占用冲突、权限越权或文档哈希检查失败时停止后续部署。
