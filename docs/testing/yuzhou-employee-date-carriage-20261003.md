## 改动与来源

原 person.injobdate、person.awaydate 已映射为 hr_employee.hire_date、departure_date；现有 projectHrEmployee 及 Web HrEmployee 类型已返回 hireDate/departureDate。员工详情原来没有展示这两个返回字段，本轮在已有选中员工区域增加 Design System 日期卡片：本单位入职日期、离职日期。日期原样显示，不通过 Date 转换时区，null/undefined显示未登记。

只有已通过现有员工读取授权和详情读取的记录才渲染。未增加API请求、读写权限、数据库迁移或日期写入，没有重放历史导入。

## 转正日期另行保留语义问题

原 web_formal_r 明确将 formaldate 输出为转正日期，过程SHA256 b47833d9bc5ad81e34dfd7a417cd55754802d77ca4ab76b0a10435ed774d6c4d。当前源映射把 formaldate 存入 probation_end_date；现代DTO及转正生效流程也使用该属性。员工投影与页面仍未承载该属性。不能把原转正日期直接标作计划试用结束日期，后续需独立区分原始历史事实、现代计划日期与实际生效日期；本轮不改变存储值或扩大字段等价信用。
